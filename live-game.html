選一個容得下這次練習的棋盤。

5×5、7×7、9×9 與 19×19 是不同尺度的練習入口，不是能力階梯。

這一頁怎麼用：5×5／7×7 適合練規則與局部判斷，9×9 是完整小棋盤，19×19 是完整棋盤練習。這裡的對局主要用來練習與保存棋譜，不會只靠一盤勝負就判定你的棋力。

5×5連斷與眼形 7×7局部攻防 9×9完整小棋盤 19×19全盤整合
對手練習電腦適合直接開始練習

第一次使用不需要安裝其他程式，也不需要申請 API 金鑰；選「練習電腦」即可開始。

進階：更換電腦引擎

這裡是進階設定，不影響一般初學練習。無法連線時會停止電腦回合，不會偷偷改用另一個引擎。

KataGo 是什麼？

它是獨立的圍棋 AI 引擎，不是使用本頁的必要條件。這個網站本身不能直接執行 KataGo；此模式只會連到你目前裝置上已啟動的本機連接程式。其他使用者如果沒有自行安裝並啟動，就不能使用「本機 KataGo」模式。

遠端對弈 API（跨裝置／網站訪客）

如果要讓不同裝置或網站訪客共用 KataGo，需要另外架設可連線的 HTTPS KataGo API，再把連線位址填在這裡。目前專案沒有提供共用的 KataGo 服務。本頁只保存連線位址，不會要求或保存 API 金鑰；如果服務需要密鑰，應由你自己控制的伺服器或 Cloudflare Worker 保存。

黑棋先下。滑鼠、觸控或鍵盤方向鍵移動，Enter／空白鍵落子。

看懂棋盤上的規則與檔案名詞
停一手（Pass）
這一回合不落子，把行棋權交給對方；雙方連續各停一手後，本頁進入終局確認。
死子
終局時雙方同意已無法逃脫、應從盤上移除的棋。系統不自動判死活，有爭議就繼續下。
中國式面積
本頁把盤上活棋與其圍住的空點一起計入面積，再加上貼目比較結果。
貼目
為補償白棋後下，在最後計分時加給白棋的點數；9×9 本頁目前使用 7.5。
簡單劫
剛提子後不能立刻回到上一個棋形；先到別處走一手後，是否能再提要重新依局面判定。
SGF 棋譜檔
常見的純文字圍棋棋譜格式，可保存棋盤尺寸、手順、Pass、貼目與結果等資料。
兩次 Pass

確認終局與死子

點選棋盤上的棋串可標記／取消死子。系統不自動判死活；若雙方有爭議，請繼續下棋。
