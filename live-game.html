棋盤練習

依目前學習階段選擇 5×5、7×7 或 9×9 棋盤。

證據邊界：5×5／7×7 是基礎與過渡練習盤；9×9 才定位為完整小棋盤對局。這裡全部屬 practice，不自動成為正式 T2／T3 或棋力評量。

5×5連斷與眼形 7×7局部攻防 9×9完整對局
對手練習電腦適合直接開始練習

第一次使用不需要安裝 AI、申請 API key 或理解 KataGo；選「練習電腦」即可開始。

進階：更換電腦引擎

這裡是進階設定，不影響一般初學練習。無法連線時會停止電腦回合，不會偷偷改用另一個引擎。

KataGo 是什麼？

它是獨立的圍棋 AI 引擎，不是使用本頁的必要條件。GitHub Pages 不能執行 KataGo；此模式只連你目前裝置上已啟動的悟之一手 localhost bridge。其他網站使用者若未自行安裝並啟動 bridge，就不能使用這個「本機 KataGo」模式。

前往 KataGo 官方下載頁 ↗
遠端對弈 API（跨裝置／網站訪客）

GitHub Pages 只提供靜態前端；若要讓所有訪客共用 KataGo，需要另行部署 HTTPS KataGo API，再把端點填在這裡。目前專案沒有提供共用的託管 KataGo 服務。本頁只保存 endpoint，不提供、要求或保存 API key；需要密鑰時應由你控制的 server／Cloudflare Worker 保存 secret。
